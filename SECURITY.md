# Security policy

## Supported versions

The site at [aedis.build](https://aedis.build) is deployed from `main`; only `main` is supported.

## Reporting a vulnerability

Use **Report a vulnerability** in this repository's Security tab (GitHub Private Vulnerability Reporting). Do not open a public issue for vulnerabilities.

- Acknowledgement within 3 business days.
- Initial severity assessment (CVSS) within 7 days.
- Fix or documented mitigation for high/critical severity within 30 days.
- Credit to the reporter in the advisory, if desired.

## Scope

The aedis.build site, its response headers and its build tooling. The components it uses are covered by [aedis-build/aedis-ui](https://github.com/aedis-build/aedis-ui/security/policy) and the .NET packages by [aedis-build/aedis-dotnet](https://github.com/aedis-build/aedis-dotnet/security/policy).
